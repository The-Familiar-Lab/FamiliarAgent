# Source attribution and local modifications

FamiliarAgent is a modified distribution of [Paseo](https://github.com/getpaseo/paseo), copyright its original authors and contributors, under Apache-2.0. The complete license remains in LICENSE; original package metadata, source notices and upstream README are preserved. The pinned source commit is in UPSTREAM.json. FamiliarAgent is a separate local product identity and is not an official Paseo release.

[AI Agent Discord Connector](https://github.com/kwonminki/ai-agent-discord-connector) by kwonminki is reused under MIT in integrations/discord-connector. Its LICENSE and original source are retained. The pinned commit and local integration changes are recorded there. Bundled third-party JavaScript retains esbuild legal comments. The desktop distribution includes the original project licenses in Resources/licenses and a generated THIRD-PARTY-DISCORD.txt alongside the bridge. Notices missing from two published Sapphire packages are preserved from their npm gitHead commits under packages/desktop/scripts/third-party-licenses.

Local changes: isolated desktop identity/data/update configuration; user-scoped SSH bootstrap and verified runtime overlays; built-in workspace plugin and CLI/MCP access; shared context revisions, native agent requests/permissions and bounded artifact transfer; streamed media and native downloads; opt-in Discord process/configuration UI; native provider sign-in terminal; build-time built-in compilation; headless validation scripts and focused regression tests. Existing provider/model loops and original workspace UI are retained.

Conversation history readers adapt Orca (MIT) and txcript (Apache-2.0) field mappings and use Antigravity-Mobility-CLI (MIT) as the reference for read-only local RPC discovery. Pinned commits, original copyright and full licenses are in plugins/familiar-workspace/THIRD-PARTY.txt in the source tree and builtin-plugins/familiar-workspace/THIRD-PARTY.txt in the packaged app. The noncommercial google-antigravity-export implementation is not incorporated. Other projects in the research directory were analyzed but their source is not silently bundled into this application. Source reuse here does not imply every researched tool has a FamiliarAgent adapter.
